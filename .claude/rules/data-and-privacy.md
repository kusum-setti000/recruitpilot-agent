# Data, sources and privacy rules

- All profiles in `data/` are synthetic and generated by `scripts/generate_dummy_data.py`. Edit the generator, not the JSON, then regenerate.
- Never add real people's data to the repo, tests or fixtures.
- New sources implement `agent/sources/base.py::CandidateSource`, normalise into `Candidate`, and register in `agent/sources/__init__.py`. Matching and LLM code must not change when a source is added.
- LinkedIn: no scraping, no unofficial APIs. Only partner APIs (LinkedIn RSC via an ATS) or licensed data vendors whose terms allow this use.
- Store API keys only in `.env`. Read them via `agent/config.py`.
- Hiring is a regulated use of AI (EEOC guidance, NYC Local Law 144, EU AI Act high-risk category). Keep decisions explainable: every score must be traceable to `ScoreBreakdown`, and the final report must state gaps and risks, not only strengths.
- Do not add features that filter or rank on age, gender, ethnicity, nationality, photos or names.
